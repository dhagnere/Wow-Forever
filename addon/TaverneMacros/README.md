# TaverneMacros

Les macros de votre classe, créées en un clic, pour les neuf classes. Addon de La Taverne Éternelle.

## Commandes

| Commande | Effet |
|---|---|
| `/tm installer` | crée (ou met à jour) les macros de la classe du personnage |
| `/tm liste` | affiche les macros de la classe et leurs touches |
| `/tm nourriture <nom>` | chasseur : nourriture ajoutée à la macro « Nourrir » |
| `/tm retirer` | supprime les macros créées par l'addon |

Les macros arrivent dans l'onglet du personnage (Échap > Macros) : glissez-les sur vos barres.
Le nom de chaque sort vient du jeu, d'après son identifiant : elles marchent avec un client français comme anglais.
Un sort pas encore appris n'empêche pas l'installation : la macro servira dès qu'il sera connu.
Identifiants et noms de secours lus dans les fichiers du jeu de Forever. Une macro ne lance qu'un sort par appui :
l'addon ne joue pas à votre place.

Touches : **Maj**, **Ctrl** et **Alt** choisissent une variante en appuyant sur la macro. « Survol » : la cible
sous la souris passe avant votre cible, puis vous-même pour un soin ou un renfort.
